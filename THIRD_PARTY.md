# Third-party software

The Bureau is licensed under the [MPL-2.0](LICENSE). It builds on the open-source projects below, each under its own
licence (the full texts ship with each package in `node_modules/` and the Cargo registry). Only direct dependencies
are listed; `cargo metadata` and `npm ls` give the full trees.

| Crate | Used for | Licence |
|---|---|---|
| [IronCalc](https://github.com/ironcalc/IronCalc) (`ironcalc_base`) | Spreadsheet calculation in `oel-xlsx` | MIT OR Apache-2.0 |
| [wgpu](https://wgpu.rs) / naga | GPU image pipeline in `oel-img` | MIT OR Apache-2.0 |
| image, moxcms | Image decoding, ICC colour management | MIT OR Apache-2.0; BSD-3-Clause OR Apache-2.0 |
| zip | OPC packages (`oel-opc`) | MIT |
| serde, serde_json | JSON contract with the editors | MIT OR Apache-2.0 |
| csv, encoding_rs | CSV dialects and encodings (`oel-xlsx`) | Unlicense OR MIT; (Apache-2.0 OR MIT) AND BSD-3-Clause |
| wasm-bindgen, js-sys, web-sys, wasm-bindgen-futures, console_error_panic_hook | WebAssembly bindings | MIT OR Apache-2.0 |
| bytemuck, pollster | GPU buffers, blocking on GPU work in tests | Zlib OR Apache-2.0 OR MIT; Apache-2.0 OR MIT |
| ts-rs (dev) | Generating the TypeScript contract types | MIT |

# Demo Bureau files

The files the Bureau puts on a new desk (plan `docs/plans/2026-10-solo-mvp.md`, S-3 and S-4).
Generated by `make_demo.py` (instructions at its top); edit the script, not the files.

| File | Content |
|---|---|
| `Chronos — tours de piste.xlsx` | `Tours`: 18 lap times of six fictional runners. `Résultats` (first tab): best lap `MINIFS`, average `AVERAGEIFS`, gap to the best, rank `RANK.EQ`, « En bref » with `MIN`, `XLOOKUP` (who ran the fastest lap), `COUNTA`, `AVERAGE`; a clustered column chart « Meilleur tour par coureur ». Formulas are English; results and chart caches are baked by `cargo run -p oel-xlsx --example recalc` |
| `Bienvenue dans le Bureau.pptx` | 16:9, four slides: intro with the logo, « Comment l’utiliser » (three tips), « Résultats de la course » (chart « Graphique du tableur », same numbers; on the desk it becomes a linked copy of the workbook's chart), « Merci ! » white on black |
| `À propos du Bureau.docx` | Title, the logo (inline picture), three paragraphs about the Bureau, a shortcut table |
| `logo.svg`, `logo.png` | The OutilsEnLigne mark (`apps/web/public/favicon.svg`, same as `Logo.tsx`), 1024 px PNG made with ImageMagick |

Tests: `crates/oel-xlsx/tests/demo.rs`, `crates/oel-pptx/tests/demo.rs`, `crates/oel-docx/tests/demo.rs`,
and the desk preview of the workbook in `packages/engine/test/engine.test.ts`.
